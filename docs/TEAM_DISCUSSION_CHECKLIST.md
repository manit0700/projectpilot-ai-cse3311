# Team Discussion Checklist

Use this list during team meetings.

## Project Direction

- Are we keeping the name ProjectPilot AI?
- Are students our first target user group?
- Are we keeping the MVP single-user?
- Are we focusing on class, hackathon, and portfolio projects?

## MVP Scope

- Project idea input
- Clarifying questions
- Requirements summary
- Task breakdown
- Dependency ordering
- Agent assignment board
- Human approval checkpoints
- Review output page
- Feedback and revision loop

## Team Roles

For four people, use this split:

1. Vision, users, competitors, sources
2. Workflow, manager agent, agent communication
3. Architecture, data model, risks, evaluation
4. MVP features, prototype, timeline, demo, Q&A

## Decisions Needed

- Who owns each section?
- Who presents each section?
- Who updates the deck?
- Who collects user feedback?
- Who manages the GitHub repo?
- Which AI API do we plan to use first?

## Prototype Screens

- Project input
- Clarifying questions
- Requirements summary
- Task breakdown
- Agent assignment board
- Review output
- Feedback and revision
- Final project plan

## Q&A Prep

- How do agents communicate?
- How are we different from ChatGPT?
- How are we different from ChatDev or MetaGPT?
- What happens when AI output is wrong?
- Who is the target user?
- What is included in the MVP?
- How will we measure usefulness?
